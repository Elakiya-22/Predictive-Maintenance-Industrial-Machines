# Predictive Maintenance of Industrial Machines

## Overview
A machine learning project that predicts industrial machine failures using sensor data.

## Features
- Predict machine failures
- Random Forest Classification
- Streamlit Web Application
- 98.35% Accuracy

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Git & GitHub

## Run Locally

pip install -r requirements.txt

streamlit run app1.py
